# Taskly frontend

## Setup

1. Ensure the Taskly backend is configured and running on port `8000`.
2. Copy `.env.example` to `.env` (the default API URL targets `http://localhost:8000/api/v1`).
3. From this folder, run `npm install` and `npm run dev`.

Vite prints the local URL to open in your browser. The backend must be running on port 8000 for sign-in and task data to work.
